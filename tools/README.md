# ساخت دوباره‌ی داده‌ی اپ

فایل `app/src/main/assets/waqiah.json` دستی نوشته نشده — از منابع بیرونی گرفته
و ساخته می‌شود. مراحل به ترتیب:

```bash
node tools/fetch-quran.js     # متن عثمانی + ۴ ترجمه → tools/raw.json
node tools/fetch-tafsir.js    # تفسیر نور (قرائتی) → tools/tafsir_noor.json
node tools/build-data.js app/src/main/assets/waqiah.json
```

دو فایل میانی (`raw.json` و `tafsir_noor.json`) داخل ریپو کامیت شده‌اند تا
ساختن دوباره‌ی فایل نهایی به در دسترس بودن سایت‌های منبع وابسته نباشد. اگر
متن‌ها را دوباره از منبع می‌گیرید، خروجی را با تست‌های
`app/src/test/.../WaqiahContentTest.kt` بسنجید.

`build-data.js` پیش از نوشتن فایل، خودش این‌ها را بررسی می‌کند و در صورت خطا
با کد خروجی غیرصفر متوقف می‌شود:

- دقیقاً ۹۶ آیه وجود دارد و متن عربی هیچ‌کدام خالی نیست
- هر چهار ترجمه برای هر ۹۶ آیه پر است
- بخش‌های تفسیر، همه‌ی آیه‌های ۱ تا ۹۶ را پوشش می‌دهند
- جمعِ تلاوت‌های ختم چهارده‌روزه ۱۰۵ و ختم یک‌هفته‌ای ۴۱ است

## منابع

| بخش | منبع |
|---|---|
| متن عثمانی سوره | مصحف عثمانی Tanzil، از طریق `api.alquran.cloud` |
| ترجمه‌ها | انصاریان، الهی قمشه‌ای، قرائتی، مکارم شیرازی — `api.alquran.cloud` |
| تفسیر | تفسیر نور، محسن قرائتی — دانشنامه‌ی اسلامی (`wiki.ahlolbait.com`) |
| شأن نزول و فضایل | مجمع البیان طبرسی و المیزان علامه طباطبایی — دانشنامه‌ی اسلامی |
| ختم چهارده‌روزه و دعاهایش | مرکز تنظیم و نشر آثار آیت‌الله بهجت (`bahjat.ir`) — بهجت‌الدعا ص۳۶۲–۳۶۴ |
| بقیه‌ی روش‌های ختم | بیتوته و علم‌تو |
| خط قرآنی | `KFGQPC HAFS Uthmanic Script` — مجمع ملک فهد |
| فونت رابط کاربری | وزیرمتن (Vazirmatn)، مجوز SIL OFL |

متنِ روش‌های ختم و دعاها عیناً از منبع نقل شده‌اند و در `build-data.js` به‌صورت
رشته‌ی ثابت نشسته‌اند — یعنی برای بازتولیدشان لازم نیست آن سایت‌ها بالا باشند.
