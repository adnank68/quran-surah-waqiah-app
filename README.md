# ختم سوره واقعه

اپلیکیشن اندروید برای ختم سوره واقعه: متن سوره با خط عثمان‌طه، چهار ترجمه‌ی
فارسی، برنامه‌ی ختم دوره‌ای با تیک روزانه و نمودار پیشرفت، یادآور روزانه،
روش‌های ختم از منابع معتبر، شأن نزول و فضایل، و تفسیر کامل سوره.

اپ **کاملاً آفلاین** است؛ هیچ دسترسی اینترنتی در مانیفست ندارد و هیچ داده‌ای
از دستگاه بیرون نمی‌رود.

## امکانات

| بخش | توضیح |
|---|---|
| متن سوره | هر ۹۶ آیه با خط عثمان‌طه (`KFGQPC HAFS Uthmanic Script`) |
| ترجمه‌ها | انصاریان، الهی قمشه‌ای، قرائتی، مکارم شیرازی — کاربر هرکدام را بخواهد زیر آیه می‌بیند (چندتایی هم می‌شود) |
| اندازه‌ی متن | اندازه‌ی متن عربی و ترجمه جدا از هم قابل تنظیم است |
| برنامه‌ی ختم | چهار روش نقل‌شده از منابع، به‌علاوه‌ی برنامه‌ی دلخواه؛ هر روز یک چک‌باکس |
| نمودار پیشرفت | حلقه‌ی دایره‌ای با درصد — بر پایه‌ی تعداد تلاوت، نه تعداد روز |
| یادآور | کاربر ساعت دلخواه را انتخاب می‌کند؛ یادآور می‌گوید امروز چند مرتبه مانده |
| روش‌های ختم | متن هر روش با شرایط، دعاهای عربی + ترجمه، و منبع |
| شأن نزول و فضایل | نزول سوره، محتوا و روایات فضیلت با ذکر منبع |
| تفسیر | تفسیر نور (محسن قرائتی) برای هر ۹۶ آیه، در ۱۸ بخش |

## معماری

اندروید نیتیو، Kotlin + Jetpack Compose. بدون بک‌اند، بدون دیتابیس:

```
app/src/main/
├── assets/waqiah.json          محتوای اپ (۱۴۸ کیلوبایت)
├── res/font/                   خط عثمان‌طه + وزیرمتن
└── java/ir/almasbu/waqiah/
    ├── data/                   مدل‌ها، خواندن asset، برنامه‌ی ختم، تنظیمات
    ├── notify/                 زمان‌بندی و نمایش یادآور
    ├── ui/                     تم، ViewModel، ناوبری و صفحه‌ها
    └── util/                   تقویم شمسی و ارقام فارسی
```

- **ذخیره‌سازی**: `SharedPreferences` با یک JSON کوچک. حجم داده (یک برنامه‌ی
  ختم + چند تنظیم) اندازه‌ی Room را ندارد.
- **یادآور**: `AlarmManager` و نه `WorkManager` — چون کاربر ساعت مشخصی انتخاب
  می‌کند و کار دوره‌ای WorkManager بازه‌ی خطای پانزده‌دقیقه‌ای دارد. هر بار که
  زنگ می‌خورد، زنگ روز بعد دوباره تنظیم می‌شود، و `BootReceiver` بعد از
  ری‌استارت/به‌روزرسانی/تغییر ساعتِ سیستم آن را برمی‌گرداند. اگر اجازه‌ی «زنگ
  دقیق» داده نشده باشد، به آلارم غیردقیق برمی‌گردد.
- **تقویم شمسی**: پیاده‌سازی الگوریتم برکوفسکی (همان که `jalaali-js` دارد) با
  جدول سال‌های شکست، نه فرمول تقریبی ۳۳ساله؛ با تست واحد در برابر تاریخ‌های
  شناخته‌شده و رفت‌وبرگشتِ روزبه‌روزِ ۹۰ ساله مهار شده است.

## داده و منابع

هیچ‌کدام از متن‌های مذهبی این اپ نوشته‌ی توسعه‌دهنده یا تولیدشده‌ی ماشین نیست؛
همه از منابع بیرونی نقل شده‌اند و منبع هرکدام داخل خود اپ (بخش «تنظیمات ←
منابع محتوا») و در [`tools/README.md`](tools/README.md) آمده است.

فایل `assets/waqiah.json` با اسکریپت‌های `tools/` بازتولیدشدنی است.

## ساخت APK

روی ماشین توسعه‌ی این پروژه Android SDK نصب نیست، پس همه‌چیز روی GitHub Actions
ساخته می‌شود ([`.github/workflows/build.yml`](.github/workflows/build.yml)):
JDK 17 → Android SDK → bootstrap کردن Gradle 9.3.1 → ساخت کلید دیباگ با
`keytool` → `testDebugUnitTest` → `assembleRelease`.

APK هم به‌عنوان artifact همان اجرا و هم به‌عنوان یک GitHub Release منتشر می‌شود.
