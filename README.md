# اپلیکیشن ختم سوره واقعه 📱

اپلیکیشن موبایلی جامع برای ختم سوره واقعه با ویژگی‌های متنوع

## ویژگی‌های اصلی

### 1. 📖 متن قرآن
- متن سوره واقعه با خط عثمان طه
- رابط کاربری دوست‌داشتنی و قابل‌خوندن

### 2. 🌐 ترجمه‌های متعدد
- ترجمه شیخ انصاریان
- ترجمه الهی قمشه‌ای
- ترجمه قرائتی
- ترجمه مکارم شیرازی
- نمایش تمام ترجمه‌ها به صورت تگ‌های انتخابی

### 3. 📅 برنامه‌ی ختم دوره‌ای
- تعیین برنامه‌ی دوره‌ای برای ختم سوره
- چک‌باکس برای هر روز
- پیگیری پیشرفت روزانه

### 4. 📊 نمودار دایره‌ای
- نمایش درصد پیشرفت ختم
- به‌روزرسانی خودکار

### 5. 🔔 نوتیفیکیشن
- تعیین زمان یادآوری روزانه
- یادآوری برای انجام ختم

### 6. 🕌 راهنمای ختم
- روش ختم از منابع معتبر:
  - مفاتیح الجنان
  - آیت‌الله بهجت
  - حاج آقا عالی
  - دیگر علما و مراجع

### 7. ✨ شان نزول و فضایل
- معلومات درباره‌ی نزول سوره
- فضایل و برکات سوره واقعه

### 8. 📚 تفسیر سوره
- تفسیر حاج آقا قرائتی
- تفسیر نور
- تفاسیر دیگر

## تکنولوژی‌های استفاده‌شده

- **Frontend**: React Native / Flutter
- **Backend**: Node.js / Express
- **Database**: SQLite (موبایل) / MongoDB
- **Notifications**: Firebase Cloud Messaging

npm start
